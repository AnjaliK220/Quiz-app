# Interactive Quiz Game Application

An interactive web-based Multiple-Choice Quiz Game application developed as part of my Web Development Internship. The application dynamically renders different types of questions, handles user responses, and tracks the score in real-time.

---

## 🚀 Features

- **Dynamic UI:** Clean and modern dark-themed user interface.
- **Multiple Question Types:**
  - **Single-Select:** Traditional multiple-choice questions using radio buttons.
  - **Multi-Select:** Questions with multiple correct answers using checkboxes.
  - **Fill in the Blanks:** Text input-based questions.
- **Real-Time Score Tracking:** Updates the score instantly after each answer and displays a final scorecard at the end.
- **Interactive Feedback:** Alerts the user immediately if the answer is correct or incorrect.

---

## 🛠️ Tech Stack Used

- **HTML5:** For structuring the quiz layout.
- **CSS3:** For modern styling and a dark-theme responsive design.
- **JavaScript (ES6):** For DOM manipulation, state management, and quiz logic.
